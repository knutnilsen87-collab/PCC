3. FACTS AND CAUSAL BRIDGE
============================================================

facts:
  - Previous implementation only prepared a renderer adapter and still relied on a Vite browser tab for launch.
  - Browser folder input can trigger "Vil du laste opp X filer til dette nettstedet?" and is unacceptable for PCC production desktop.
  - Electron provides a Windows .exe runtime and native folder picker via dialog.showOpenDialog.
  - The renderer already consumes safe ScannableEntry records and creates ProjectAnalysisSnapshot through the existing import pipeline.

causal_bridge:
  problem_observed: PCC still behaved like a website at 127.0.0.1 and could show browser upload warnings.
  hypothesized_cause: No packaged desktop runtime layer existed; only the web/Vite renderer path was active.
  change_made: Added Electron main/preload, packaged .exe build, native folder picker IPC, read-only scanner in main process, desktop runtime detection, and removed browser folder input from desktop mode.
  expected_effect: Packaged PCC opens as an .exe, loads local file:// renderer, shows Desktop mode active, opens native Windows folder picker, scans selected folder locally, and creates a project named from folder basename.
  evidence_that_effect_happened:
